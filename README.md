# DecodeLabs Python Internship

This repository contains the Python tasks I completed during my DecodeLabs Internship. These projects helped me improve my understanding of basic Python concepts and problem-solving skills.

## Tasks

### Task 1: To-Do List
A simple program that lets users add tasks to a list and display all the saved tasks.

### Task 2: Expense Tracker
A program that takes multiple expense amounts from the user and calculates the total amount spent.

### Task 3: Random Password Generator
A program that generates a random password based on the length entered by the user using letters and numbers.

## Technologies Used
- Python 3
